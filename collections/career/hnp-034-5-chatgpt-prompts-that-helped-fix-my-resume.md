# 5 ChatGPT prompts that helped fix my resume

[← All prompt packs](../../CATALOG.md) · **Career** · [Original post ↗](https://www.reddit.com/r/Resume/comments/1s14qhf/i_used_chatgpt_to_fix_my_resume_and_started/)

## Prompts

Copy a prompt and replace the bracketed text with your own context.

### 1. Match a job description

```text
Rewrite my resume to match this job description: [paste job + resume]
```

### 2. Achievement-based bullets

```text
Turn my responsibilities into achievement-based bullet points with metrics
```

### 3. ATS keywords

```text
Optimize my resume for ATS using keywords from this job description
```

### 4. Results-driven summary

```text
Improve my resume summary to sound more results-driven and specific
```

### 5. Missing skills and keywords

```text
Identify missing skills or keywords in my resume for this role
```
