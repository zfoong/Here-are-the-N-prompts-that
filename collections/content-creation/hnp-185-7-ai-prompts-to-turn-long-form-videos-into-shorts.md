# 7 AI prompts to turn long form videos into shorts

[← All prompt packs](../../CATALOG.md) · **Content Creation** · [Original post ↗](https://www.facebook.com/jonathanjmast/posts/7-ai-prompts-to-turn-long-form-videos-into-shorts/25167600392846124/)

## Prompts

Copy a prompt and replace the bracketed text with your own context.

### 1. Hook Hunter: Find Viral Openings

```text
Act as a [short-form video content strategist] specializing in [YouTube Shorts/TikTok/Instagram Reels]. You're given this transcript: [PASTE TRANSCRIPT]. Extract the 5 most attention-grabbing moments and rewrite them as snappy opening hooks that immediately stop scrolling. Each hook must be under [12 words].
```

### 2. Clip Segment Selector: Identify Short-Worthy Moments

```text
Act as a [content repurposing editor]. Given this transcript: [PASTE TRANSCRIPT], identify [X] short, self-contained segments that would work as independent clips. Each should be [30–60 seconds] long and include a suggested hook at the beginning and a clear takeaway at the end. Format with timestamps if possible.
```

### 3. Platform Optimizer: Tailor Shorts by Channel

```text
You are a [social media strategist] skilled in adapting content for different platforms. Using this transcript: [PASTE TRANSCRIPT], create 3 variations of a short-form clip under [60 seconds]. Tailor one for YouTube Shorts, one for TikTok, and one for Instagram Reels. Adjust tone, caption style, and pacing to match each platform's culture.
```

### 4. Caption Generator: Add Subtitles that Stick

```text
You are a [viral video copywriter]. Using this short transcript excerpt: [PASTE SEGMENT], write on-screen captions for a [platform] short. Captions should: – Be under [7 words per line] – Use punchy, conversational phrasing – Highlight key emotional words in ALL CAPS – Include 1–2 emojis where natural
```

### 5. Cliffhanger & Curiosity Builder

```text
Act as a [storytelling coach]. Given this transcript: [PASTE TRANSCRIPT], rewrite the ending of each short clip to include a curiosity-driven cliffhanger or open loop. Each ending should tease the next part of the story or key insight in under [15 words].
```

### 6. Batch Repurposer: Generate Multiple Shorts from One Transcript

```text
Act as a [content repurposing expert]. Using this transcript: [PASTE TRANSCRIPT], generate [X] short-form clip outlines. For each, provide: – Suggested hook line – Recommended length ([30–60 seconds]) – Captions (3–4 key lines) – Call to action (CTA) Format output in a simple table.
```

### 7. Viral Angle Reframer

```text
You are a [viral content strategist]. Using this transcript: [PASTE TRANSCRIPT], reframe the same content into [3–5 different viral angles] (e.g., motivational, controversial, funny, educational). For each angle, suggest a short clip script under [60 seconds] with a strong hook and captions.
```
