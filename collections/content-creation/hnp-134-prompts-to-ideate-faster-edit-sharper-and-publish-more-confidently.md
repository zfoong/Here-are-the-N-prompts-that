# Prompts to ideate faster, edit sharper, and publish more confidently

[← All prompt packs](../../CATALOG.md) · **Content Creation** · [Original post ↗](https://www.facebook.com/adrian.anthony.brambila/posts/with-the-right-prompts-you-can-ideate-faster-edit-sharper-and-publish-more-confi/10174306366200347/)

## Prompts

Copy a prompt and replace the bracketed text with your own context.

### 1. Idea Storm Prompt

```text
Give me 10 fresh, non-cliché content ideas about [topic] that would stand out to [audience]. Rank them by originality and potential engagement.
```

### 2. Hook Builder Prompt

```text
Rewrite this intro [paste draft] into 5 different hooks: one curious, one bold, one emotional, one story-driven, and one contrarian.
```

### 3. Flow Fix Prompt

```text
Take this messy draft [paste text] and restructure it into a clear outline with logical flow, smooth transitions, and punchier subheadings.
```

### 4. Voice Match Prompt

```text
Rewrite this section [paste text] in the style of [choose tone: witty, professional, casual, inspiring]. Suggest where my tone could be more consistent.
```

### 5. Clarity Upgrade Prompt

```text
Simplify this draft [paste text] to a 7th-grade reading level without losing impact. Flag any jargon or wordiness I should cut.
```

### 6. Polish + Publish Prompt

```text
Proofread and edit this text [paste text] for grammar, conciseness, and readability. Suggest 3 improvements that would make it more engaging for [audience].
```
