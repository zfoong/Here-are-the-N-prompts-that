# 7 ChatGPT prompts for high-performing ad copy

[← All prompt packs](../../CATALOG.md) · **Business** · [Original post ↗](https://www.facebook.com/altiamkabir/posts/7-chatgpt-prompts-to-create-engaging-high-performing-ad-copy-that-reduces-your-c/24790303760603969/)

## Prompts

Copy a prompt and replace the bracketed text with your own context.

### 1. Persuasive Product Description

```text
Write a concise and persuasive product description for [Product Name]. Highlight the key benefits and use strong, active language. Target audience: [Target Demographic].
```

### 2. Hooking Headline

```text
Write a captivating headline for a Facebook ad promoting [Product/Service]. The headline should be short, attention-grabbing, and create curiosity.
```

### 3. Engaging Call-to-Action

```text
Write a strong call-to-action for a Facebook ad promoting [Product/Service]. The CTA should be clear, concise, and encourage immediate action.
```

### 4. Compelling Ad Copy for Specific Offer

```text
Write ad copy for a Facebook ad promoting a [Discount/Promotion]. The copy should highlight the urgency and value of the Offer. Target audience: [Target Demographic].
```

### 5. A/B Testing Ad Copy

```text
Write two different versions of ad copy for a Facebook ad promoting [Product/Service]. One version should focus on [Benefit 1], and the other should focus on [Benefit 2].
```

### 6. Creating Urgency

```text
Write ad copy for a Facebook ad promoting a limited-time Offer. Use strong language to create a sense of urgency and encourage immediate action.
```

### 7. Leveraging Social Proof

```text
Write ad copy for a Facebook ad that leverages social proof. Use customer testimonials, reviews, or influencer endorsements to build credibility and trust.
```
