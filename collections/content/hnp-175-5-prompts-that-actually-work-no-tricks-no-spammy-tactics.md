# 5 prompts that actually work — no tricks, no spammy tactics

[← All prompt packs](../../CATALOG.md) · **Content & Marketing** · [Original post ↗](https://www.facebook.com/simplydigital.gr/posts/5-prompts-that-actually-work-no-tricks-no-spammy-tactics/1365119235628532/)

## Prompts

Copy a prompt and replace the bracketed text with your own context.

### 1. 1️⃣ The Scroll-Stopping Hook Prompt

```text
Write 10 Facebook post hooks designed to stop scrolling in the first 2 seconds.

Audience: [describe your audience].

Tone: bold, clear, conversational.

No emojis. No clickbait.

Each hook must create curiosity without overpromising.
```

### 2. 2️⃣ The Authority Without Ego Prompt

```text
Write a Facebook post that builds authority in [your niche].

Structure it as:

– A common mistake people make

– Why it happens

– A better way to approach it

End with a natural line encouraging people to follow for more insights.
```

### 3. 3️⃣ The Relatable Story Prompt

```text
Turn this idea into a short, relatable Facebook story:

[insert struggle, lesson, or realization].

Use short paragraphs.

Write like a real person, not a marketer.

End with a simple reflection, not a CTA.
```

### 4. 4️⃣ The Comment Catalyst Prompt (Clean Version)

```text
Write 5 Facebook posts on [topic] that naturally invite discussion.

End each post with a thoughtful, open-ended question.

No 'comment YES', no forced interaction.
```

### 5. 5️⃣ The Save-Worthy Value Prompt

```text
Write a Facebook post that teaches one clear, practical idea related to [your niche].

No fluff.

No motivation quotes.

Explain it so simply that someone could apply it today.
```
