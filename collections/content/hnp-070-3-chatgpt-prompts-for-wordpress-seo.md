# ⚡ ChatGPT Prompts That Took My WordPress Site from Nowhere to #1 in Google 🔍

[← All prompt packs](../../CATALOG.md) · **Content & Marketing** · [Original post ↗](https://www.reddit.com/r/SEOorganic/comments/1oe7kjz/chatgpt_prompts_that_took_my_wordpress_site_from)

## Prompts

Copy a prompt and replace the bracketed text with your own context.

### 1. 1️⃣ Keyword Intent Analyzer

```text
Act like an SEO strategist. For the keyword [insert keyword], tell me the real user intent, top 3 subtopics Google expects, and how to structure the content for EEAT.
```

### 2. 2️⃣ SEO-Optimized Content Brief

```text
Create a WordPress-ready blog outline for [topic]. Include H2/H3 structure, FAQs, and call-to-action suggestions that match search intent.
```

### 3. 3️⃣ Content Rewriter with SEO Flow

```text
Rewrite this paragraph in active voice, keep readability high, reduce fluff, and naturally blend in these keywords: [list]. Don’t sound robotic.
```
