# 30 copy-paste prompts to turn ChatGPT into your daily growth engine

[← All prompt packs](../../CATALOG.md) · **Productivity & Life Admin** · [Original post ↗](https://www.facebook.com/altiam.artificialintelligence/posts/use-these-30-copy-paste-prompts-to-turn-chatgpt-into-your-daily-growth-engine-st/122172546164620880/)

## Prompts

Copy a prompt and replace the bracketed text with your own context.

### 1. Quick Starter Prompt

```text
Act as a [role]. My goal is [goal]. Context: [details]. Output as [format]. Constraints: [rules]. Ask 3 questions if needed.
```

### 2. Detailed Instruction Template

```text
Give me step by step instructions to [task]. Include tools, time estimate, and common mistakes.
```

### 3. Role Play Specialist Template

```text
Act as a [expert]. Help me [problem]. Ask for missing info first.
```

### 4. SOP Builder Template

```text
Turn this process into an SOP: [process]. Include checklist, owner, and done criteria.
```

### 5. Troubleshoot Template

```text
Diagnose why [thing] is failing. Give 10 causes ranked by likelihood, then tests to confirm.
```

### 6. Project Plan Template

```text
Create a 7 day plan for [goal] with daily tasks, dependencies, and success metrics.
```

### 7. Explain Like I'm Five (ELI5) Template

```text
Explain [concept] like I'm 5 using a simple analogy and 3 examples.
```

### 8. Teach Me Template

```text
Teach me [topic] in 30 minutes. Include a mini quiz and answers.
```

### 9. Critique Template

```text
Review this: [text]. Point out gaps, risks, and rewrite it stronger.
```

### 10. Pros and Cons Template

```text
List pros and cons of [choice]. Then recommend one option based on [my situation].
```

### 11. Comparison Table Template

```text
Create a table comparing [items] by [criteria]. Add a final recommendation.
```

### 12. Summary Template

```text
Summarize this in 5 bullets, then 3 action steps: [text or link notes].
```

### 13. Template Generator

```text
Create a reusable template for [thing]. Include placeholders and an example filled in.
```

### 14. Swipe File Template

```text
Give me 20 hook ideas for [topic] in styles: how to, mistake, myth, checklist, story.
```

### 15. Rewrite Template

```text
Rewrite this for [platform] in [tone]. Keep under [limit]. Add 5 headline options.
```

### 16. ICP Template

```text
Define my ideal customer for [product]. Give pains, desires, objections, and triggers.
```

### 17. Offer Template

```text
Create 5 offers for [audience] based on outcomes. Include pricing angles and guarantees.
```

### 18. Landing Page Template

```text
Write a landing page for [offer]. Include hero, benefits, proof, FAQ, and CTA.
```

### 19. Content Calendar Template

```text
Build a 14 day content plan for [topic]. Include post type, hook, and CTA each day.
```

### 20. A B Test Template

```text
Give me 10 variations of this hook: [hook]. Keep meaning, change wording.
```

### 21. Cold Email Template

```text
Write a cold email to [ICP] about [offer]. 120 words max. 2 subject lines.
```

### 22. Follow Up Template

```text
Write 3 follow ups for this email thread: [thread]. Keep each under 70 words.
```

### 23. Objection Handling Template

```text
Respond to this objection: [objection]. Give 3 reply options: soft, direct, data backed.
```

### 24. Call Script Template

```text
Create a discovery call script for [offer]. Include questions, qualification, and next steps.
```

### 25. Proposal Template

```text
Draft a proposal for [client] with scope, timeline, deliverables, and pricing options.
```

### 26. Workflow Template

```text
Map my workflow for [process]. Show steps, tools, and where automation fits.
```

### 27. Automation Spec Template

```text
Write an automation spec for [task] using triggers, actions, exceptions, and fallback.
```

### 28. Meeting Notes Template

```text
Turn these notes into decisions, action items, owners, and deadlines: [notes].
```

### 29. Policy Draft Template

```text
Draft a policy for [topic]. Keep it clear, short, and include examples.
```

### 30. KPI Dashboard Template

```text
Suggest KPIs for [team]. Define each KPI, how to measure, and target ranges.
```
