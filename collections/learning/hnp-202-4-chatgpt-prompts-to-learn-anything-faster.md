# 4 ChatGPT Prompts to Learn Anything Faster

[← All prompt packs](../../CATALOG.md) · **Learning** · [Original post ↗](https://www.threads.com/@yourchatgptguide/post/DWoZ0z5jfgL)

## Prompts

Copy a prompt and replace the bracketed text with your own context.

### 1. Rapid Skill Deconstruction

```text
Act as a world-class learning strategist who specializes in accelerated skill mastery. Break down the skill [insert skill] into its smallest core components so I understand exactly what sub-skills must be learned first to avoid wasting time on unnecessary topics.
```

### 2. First-Principles Learning

```text
Teach the topic [insert topic] using first-principles thinking by stripping away complexity and explaining only the most essential concepts that everything else depends on, ensuring I build strong foundational understanding quickly.
```

### 3. Active Recall Training

```text
After teaching me the topic [insert topic], create challenging recall questions that force me to retrieve information without looking at notes, strengthening memory and improving retention dramatically.
```

### 4. High-Speed Learning Roadmap

```text
Design a compressed learning roadmap for mastering [insert skill] as efficiently as possible, prioritizing only the highest-value concepts and eliminating low-impact topics that slow down learning progress.
```
